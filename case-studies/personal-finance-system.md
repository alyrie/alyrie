# Personal Finance System

**Role-aware household financial operations application**

## The problem

Most personal-finance software assumes everyone using it needs the same information.

That was not the problem I needed to solve.

One person may need to manage cash flow, obligations, planning, account administration, and long-term records. Another may only need a clear answer to a much smaller question: what is available in the categories I use today?

The system was designed around those different jobs instead of forcing both people into the same dashboard.

## What I designed

The application separates financial administration from everyday decision-making through role-specific experiences.

The broader system includes concepts such as:

- Household envelope planning
- Spending-category visibility
- Recurring obligations
- Daily operating views
- Administrative and simplified experiences
- Important-record organization
- Future document and notification workflows

## Key product decision

The most important design choice was **not showing every user everything the system knows**.

More information can create more cognitive load. Each view is designed around the decisions that person actually needs to make.

That principle applies well beyond personal finance. Good internal tools frequently succeed because they remove irrelevant information rather than adding another dashboard.

## What this project demonstrates

- Role-based UX
- Business-rule translation

- Workflow design
- Product simplification
- Privacy-conscious system planning
- Turning spreadsheet-style processes into purpose-built software
