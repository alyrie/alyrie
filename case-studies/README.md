## What these projects demonstrate

Across these projects, my work includes problem definition, workflow architecture, UX, data modeling, AI-assisted development, full-stack implementation, testing, deployment, documentation, and iterative product improvement.

The common thread is systems thinking: understand where the friction actually lives, decide what information a person needs at each decision point, and build the system around that.
